# 🛠️ AWS Infrastructure as Code: Importing Resources & Securing Secrets

> **Overview**  
Successfully modernized AWS infrastructure management by importing existing resources into **Terraform** and implementing secure secret handling using **HashiCorp Vault**.

## 🌟 Key Highlights

### 🧱 AWS Resource Import with Terraform

- 🔄 Imported existing **EC2 instances** and **S3 buckets** into Terraform state  
- 📚 Enabled **version-controlled**, **auditable** infrastructure as code workflows  
- 📌 Improved change tracking and environment reproducibility

### 🔐 Secrets Management with Vault

- 🔗 Integrated **HashiCorp Vault** with **Terraform** for dynamic secrets handling  
- 🛡️ Secured sensitive data like **AWS credentials** and **environment variables**  
- ❌ Eliminated hardcoded secrets, boosting security and compliance posture  
- ⚙️ Enabled dynamic secret generation and revocation policies

---

## 🎯 Impact

- 🚀 Accelerated **infrastructure efficiency** and **developer productivity**
- 🔒 Strengthened **security posture** through dynamic and centralized secrets management
- 🔁 Established a **scalable, repeatable workflow** for managing infrastructure and secrets via IaC best practices
